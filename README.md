The official REST API for the United States Congress, provided by the Library of Congress. It offers public access to machine-readable legislative data including bills, amendments, laws, committee reports, the Congressional Record, nominations, treaties, CRS reports, house votes, hearings, and member information. The API is free to use and requires a key obtained via the Data.gov signup page. Responses are available in JSON or XML format, with version 3 (v3) as the current release.

**Areas:** Government · Legislative · Congress · Bills · Amendments · Members · Treaties · Nominations · Congressional Record · US Federal · Government Data

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Congress.gov API: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
