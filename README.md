# Congress.gov API

APIs.json provider profile for the Congress.gov API, operated by the Library of Congress.

The Congress.gov API is a free public REST API that provides machine-readable access to US legislative data including bills, amendments, laws, committee reports, the Congressional Record, nominations, treaties, CRS reports, house votes, hearings, and member information.

**Base URL:** https://api.congress.gov/v3  
**Signup:** https://api.congress.gov/sign-up/  
**Documentation:** https://github.com/LibraryOfCongress/api.congress.gov  
**Rate Limit:** 5,000 requests per hour  
**Authentication:** API key (free, via Data.gov)
